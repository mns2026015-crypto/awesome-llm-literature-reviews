# Tutorials and Learning Resources

This file contains authoritative tutorials, documentation, and learning resources relevant to Large Language Models, Retrieval-Augmented Generation, scientific literature retrieval, and automated literature synthesis.

## 1. Hugging Face — NLP Course

The Hugging Face NLP Course provides practical and theoretical material covering Transformers, tokenizers, datasets, model fine-tuning, and modern NLP workflows.

**Relevance:** Useful for understanding the language-model technologies underlying LLM-based literature-review systems.

[Hugging Face NLP Course](https://huggingface.co/learn/nlp-course)

---

## 2. Hugging Face Transformers Documentation

The official Transformers documentation provides information about pretrained transformer models, text generation, model loading, inference, and fine-tuning.

**Relevance:** Useful for implementing and experimenting with LLM-based text-generation systems.

[Transformers Documentation](https://huggingface.co/docs/transformers/)

---

## 3. PyTorch Tutorials

PyTorch provides official tutorials covering deep learning concepts, neural networks, model training, and implementation techniques.

**Relevance:** Useful for understanding the machine-learning infrastructure commonly used for LLM research.

[PyTorch Tutorials](https://pytorch.org/tutorials/)

---

## 4. LangChain Documentation

LangChain documentation explains how to build applications that connect language models with external data sources, retrieval systems, tools, and multi-step workflows.

**Relevance:** Useful for understanding retrieval-augmented and tool-using LLM systems.

[LangChain Documentation](https://docs.langchain.com/)

---

## 5. LlamaIndex Documentation

LlamaIndex provides documentation for connecting LLMs with external documents and data through indexing and retrieval pipelines.

**Relevance:** Useful for understanding document retrieval and knowledge-grounded LLM applications.

[LlamaIndex Documentation](https://docs.llamaindex.ai/)

---

## 6. arXiv

arXiv provides open access to research preprints across computer science and related scientific disciplines.

**Relevance:** Particularly useful for rapidly evolving research areas because new research can appear on arXiv before formal publication.

[arXiv](https://arxiv.org/)

---

## 7. ACL Anthology

ACL Anthology provides access to research publications in computational linguistics and natural language processing.

**Relevance:** Useful for finding and verifying research related to NLP, LLMs, information retrieval, and scientific text processing.

[ACL Anthology](https://aclanthology.org/)

---

## 8. OpenReview

OpenReview provides a platform for research-paper submission, peer review, discussion, and publication.

**Relevance:** Useful for tracking research that is under review and understanding the distinction between submitted, reviewed, and published research.

[OpenReview](https://openreview.net/)

---

## 9. Semantic Scholar

Semantic Scholar is a scientific literature discovery platform that provides paper search, citation information, and related research.

**Relevance:** Useful for discovering research papers and examining citation relationships when constructing literature reviews.

[Semantic Scholar](https://www.semanticscholar.org/)

---

## Learning Focus

The resources above support learning in four major areas:

| Area                           | Purpose                                                           |
| ------------------------------ | ----------------------------------------------------------------- |
| Large Language Models          | Understanding model architectures, inference, and text generation |
| Information Retrieval          | Understanding how relevant scientific documents can be retrieved  |
| Retrieval-Augmented Generation | Connecting LLMs to external and potentially newer information     |
| Scientific Literature Review   | Finding, evaluating, synthesizing, and citing research evidence   |

## Relation to the Research Topic

The central issue in this repository is that an LLM's internal knowledge may not contain the newest developments in a rapidly evolving research field. Retrieval-based approaches can provide access to external scientific information, but the retrieved evidence must still be checked for temporal relevance, source reliability, and citation correctness.

These resources provide the technical background needed to understand and investigate those issues.
